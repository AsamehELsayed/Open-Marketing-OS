## Changes

- Added `diagnose_unsupported_citations()` in `app/routes/business_workspace.py` as the shared detector. The existing `has_unsupported_citations(markdown, allowed_ids)` remains a boolean wrapper.
- Preserved the historical two-pass order, regexes, timestamp and URL exceptions, and exact canonical-span check. The diagnostic returns the first failure in that same scan order.
- Added the reason codes `unknown_bracketed_id` and `noncanonical_source_like_token`, with an allowlisted `{reason_code, token_form, token}` shape. Tokens are capped at 96 characters and credential-like, secret-like, private, and long numeric identifiers are redacted.
- Brief generation now returns the structured diagnostic on citation rejection while retaining the existing status, provider/model fields, and plain-language error. Rejected output remains unsaved.
- Campaign validation now consumes the shared diagnostic. Its scoped citation failure contains only bounded failure metadata; it omits claim excerpts, available evidence IDs, project hashes, and rejected text. Validation-before-write remains in place.
